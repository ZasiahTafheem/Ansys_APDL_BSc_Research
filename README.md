# Seismic Analysis of a Three-Span Concrete Deck Girder Bridge using Ansys APDL

This repository contains the complete scripts to model, load, and analyze a three-span concrete deck girder bridge in Ansys Mechanical APDL. The project evaluates the structural response under seismic loading using two distinct methodologies.

## 📌 Features & Methodologies
- **Parametric Structural Modeling:** Full geometry generation of a three-span concrete deck girder bridge system including columns, and deck.
- **Equivalent Static Force Method:** Application of lateral seismic forces computed via equivalent static force method.
- **Linear Dynamic Response Spectrum Analysis:** Multi-mode dynamic analysis utilizing design response spectra to capture peak displacement, bending moments, and shear forces.
